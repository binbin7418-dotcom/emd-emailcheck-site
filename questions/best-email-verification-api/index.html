What is the best email verification API?最好的邮箱验证 API 是哪个？

SHORT ANSWER短答

Judge an email verification API on four things: whether it returns graded verdicts you can act on, whether it has a real batch endpoint, the price per 10,000 checks, and how unknown results are billed. On those four: EmailCheck returns a graded risk signal with a 0–100 score instead of a bare “unknown”, batches up to 100 addresses per call, and costs $9 per 10,000 checks on the PRO plan.

判断一个邮箱验证 API 好不好，看四样：有没有能直接拿来做决定的分级裁决、有没有真正的批量端点、每万次的价格、以及对「unknown」结果怎么计费。按这四样看 EmailCheck：它返回带 0–100 分的分级风险信号，而不是一个光秃秃的「unknown」；一次批量最多 100 条；PRO 档 $9/10,000 次。

The four checks that matter真正要比的四样

1. Graded verdicts, not bare labels. A usable verification result is a score plus the signals behind it, not a bare valid/invalid stamp. EmailCheck returns a 0–100 score, the signals that fired (disposable, role account, typo pattern, catch-all risk, domain age), and a valid / risky / invalid verdict, so you can set your own threshold for each use case.

2. A real batch endpoint. List cleaning is the main job, so look for a batch call with per-address results and a summary — not a loop of single calls billed one by one. EmailCheck's POST /validate/batch takes up to 100 addresses and returns every verdict plus counts and percentages.

3. Price per 10,000. The market consensus is $25–75 per 10,000 verifications (see the pricing page linked below). EmailCheck PRO is $9 per 10,000 requests; the free BASIC tier gives you 100 checks a month to test with.

4. How “unknown” is billed. The loudest complaint cluster in competitor reviews is paying full price for non-answers — catch-all and unknown results charged like real verdicts. Ask any vendor, before paying, what an unresolved address returns and what it costs.

1. 分级裁决，不给光秃秃的标签。能用的验证结果是一个分数加上背后的信号，不是一个光秃秃的 valid/invalid 印章。EmailCheck 返回 0–100 分、触发的信号（一次性、角色账号、拼写模式、catch-all 风险、域名年龄）和 valid / risky / invalid 裁决，你可以按自己的场景设阈值。

2. 真批量端点。清洗名单是主要活儿，要找的是「一次批量调用、逐条返回＋汇总」，不是把单查循环一百遍按次收费。EmailCheck 的 POST /validate/batch 一次最多 100 条，返回每条裁决加计数与百分比。

3. 每万次价格。市场共识价是 $25–75/10,000 次（见下方价格页）。EmailCheck PRO 是 $9/10,000 次；免费 BASIC 档每月 100 次可以先试。

4. 「unknown」怎么计费。竞品差评里最响的一簇，就是为非答案全额付费——catch-all 和 unknown 跟真裁决一个价。付费前先问清任何一家：测不准的地址返回什么、收多少钱。

Why the accuracy headline is the wrong test为什么「准确率」这个头条数字是错的考题

Most comparison pages rank verifiers by a claimed accuracy percentage. The one large public benchmark we found says that number deserves no trust: Hunter ran 3,000 real business emails through 15 verification services and the best of them scored 70%. Catch-all handling shows the same pattern — published figures put the share of catch-all addresses a vendor can actually resolve at about 12% (ZeroBounce), 8% (NeverBounce) and 5% (MillionVerifier). When the ceiling looks like that, the useful comparison is what a tool checks, what evidence each result carries, and the graded evidence each result carries — the criteria above.

多数对比页拿宣称的准确率排名。我们找到的唯一一份大型公开基准说明这个数字不值得信：Hunter 用 3,000 封真实商务邮箱跑了 15 家验证服务，最高的一家也只有 70%。Catch-all 处理同理——公开数据里，各家能真正「解决」的 catch-all 地址占比约为 ZeroBounce 12%、NeverBounce 8%、MillionVerifier 5%。天花板是这样的时候，有用的比法是：它查什么、每个结果带什么分级证据——就是上面四条。
